UI Compare Privacy Policy

Last updated: 2026-08-11 · Contact: holy_nova@126.com

English

UI Compare is a local-first Chrome extension for comparing a reference design with the current web page. This policy explains what the extension stores and how it handles access.

Local storage

Uploaded design images, thumbnails, project settings, and page-comparison context are stored locally in the extension's IndexedDB database in Chrome. This can include comparison mode, opacity, dimensions, selected page elements, and notes that you choose to save.

UI Compare does not use developer-operated servers, analytics, advertising, user accounts, or login. It does not sell or share your data with third parties.

Current-page access

UI Compare requests the Chrome activeTab capability only after you trigger the extension from its toolbar action or keyboard command. The access is limited to the current tab and is temporary. The extension does not request broad host permissions and does not continuously monitor pages.

Chrome-protected pages such as chrome:// pages and the Chrome Web Store cannot be injected into by extensions. This is a browser limitation, not a request for broader permission.

Export and import

Archive export and import are user-initiated local actions. An archive is saved to or selected from your device; UI Compare does not upload it to a cloud service or developer-operated server.

Retention and deletion

Local projects remain in Chrome's extension storage until you delete them, clear the extension's local data, or uninstall the extension. You control whether to keep or delete exported archive files on your device.

Contact

For privacy questions, contact holy_nova@126.com.

中文

UI Compare 是一款本地优先的 Chrome 扩展，用于比较参考设计与当前网页。本政策说明扩展保存哪些内容以及如何处理页面访问。

本地存储

您上传的设计图片、缩略图、项目设置和页面比较上下文，都会保存在 Chrome 中扩展自己的 IndexedDB 数据库内。您主动保存的比较模式、不透明度、尺寸、选中的页面元素和备注也可能包含在其中。

UI Compare 不使用开发者运营的服务器、分析服务、广告、用户账户或登录功能，也不会向第三方出售或共享您的数据。

当前页面访问

只有当您点击扩展工具栏按钮或触发键盘命令后，UI Compare 才请求 Chrome 的 activeTab 能力。该访问仅限当前标签页并且是临时的。扩展不申请广泛的主机权限，也不会持续监控网页。

对于 chrome:// 页面和 Chrome Web Store 等 Chrome 保护页面，扩展无法注入。这是浏览器本身的限制，并不意味着需要申请更广泛的权限。

导出和导入

归档导出和导入均由您主动发起并在本地完成。归档文件保存到您的设备或从设备中选择；UI Compare 不会将其上传到云服务或开发者运营的服务器。

保存期限与删除

本地项目会保留在 Chrome 的扩展存储中，直到您删除项目、清除扩展本地数据或卸载扩展。设备上的归档文件是否保留或删除，由您自行决定。

联系

如有隐私问题，请联系 holy_nova@126.com。
